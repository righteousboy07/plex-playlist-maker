Choose what to install or update

Both components are selected by default. Use the Installer Customize option if you only need to update one component.

  • Plex Curator App — installs or updates Plex Curator.app in /Applications
  • API Backend & Automation — installs or updates the self-contained backend, localhost API, LaunchAgent tools, examples, and 30-day log-retention automation
  • Existing stations, schedules, history, configuration, and backups are preserved

The local API listens only on 127.0.0.1:8765. Plex credentials remain in your private user configuration directory and are not bundled into the application.

On a first install, the app will ask for your Plex server address and Plex token. On an upgrade, existing settings are reused automatically.
